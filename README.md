# Férias Prontas

Site de vendas do Férias Prontas · 30 dias sem tela (GitHub Pages, branch `main`).

- `index.html`: landing. O link do checkout repassa `utm_*`, `sck`, `src` e `fbclid` e é recalculado no clique.
- `amostra/`: página da amostra grátis (dias 1 a 3).

Só arquivos públicos de venda. O produto pago fica na área de membros da Kiwify.
